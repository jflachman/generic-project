# Session Protocol

1. Read [../generic/CLAUDE.md](../generic/CLAUDE.md) and [CLAUDE.md](CLAUDE.md).
2. Load the relevant prompt or work package from [QUEUE.md](QUEUE.md).
3. Update governed product truth before implementation when behavior or
   contracts change.

   before close-out when scaffold or governance files change.
5. Close every prompt session with a build report in [build-reports/](build-reports/).
